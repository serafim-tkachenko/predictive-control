# 20 September 2026

## Where the project stands

PPO training and evaluation are working. The project has two baselines: a small Empty
room and Crossing with separate train/development/test layouts. All runs so far used
full symbolic observations and CPU. Predictive pretraining has not started.

In Empty, greedy execution was misleading as the sole metric: some policies repeatedly
walked into a wall. Sampling from those same policies gives over 99.98% expected success
across all starts. The [audit](../../evidence/empty-audit-20260920/RESULTS.md) includes the
transition calculation and a separate rollout check. Use sampled actions as the primary
metric going forward, with greedy execution reported separately.

Crossing is harder. After 524,288 interactions, median train success is 48.7%; test
success ranges from 32.6% to 55.8%. Random actions reach 6.25% on test. Greedy execution
fails on all seven test maps for all three checkpoints.

The baseline did not meet the 80% train-success threshold set before the runs. This
leaves a learning problem to resolve before drawing conclusions about transfer or
the value of a predictive objective. [Full results](../../evidence/crossing-v1/RESULTS.md).

## Next session

1. Inspect training-map failures and PPO diagnostics. Check whether the agent responds
   to the opening's position or mostly follows a common movement pattern.
2. Specify one observation-encoding control. The current input treats object, colour
   and heading codes as numbers divided by 10. A categorical encoding is worth testing,
   but there is no evidence yet that these numbers explain the poor learning.
3. Before launching, fix the comparison: same map split, reward, training budget and
   sampled evaluation. If one-hot encoding changes the network's parameter count,
   account for that or report it as a confound. Avoid changing encoding, architecture
   and PPO settings together.
4. Use train and development results for this diagnosis. The seven test maps are
   already exposed. Keep the current results as v1 and write a separate protocol for
   the next experiment.

Do not start a JEPA sweep yet. First establish what the current baseline is failing
to learn. The longer-term comparison remains RL with and without predictive
representation pretraining, accounting for pretraining data and compute.
